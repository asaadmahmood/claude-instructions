# Upwork Project — files to upload

These four files are the knowledge base for the Upwork cover-letter Project on claude.ai.
Everything else in this repo is local working material and does not belong in the Project.

## What to upload

| File | Role in the Project |
|---|---|
| `project-instructions.md` | The system's rules. Paste into the Project's custom instructions box, or upload it — either works. |
| `cover-letters-data.md` | Portfolio projects with links, grouped by category. The file STEP 2 selects proposal links from. |
| `highlights.md` | Career achievements and awards. Single source of truth for the YouTube subscriber count. |
| `tech-expertise.md` | Services and technical capabilities, matched against job requirements at STEP 4. |

## Filename caution

`project-instructions.md` historically referred to these as `/mnt/project/Cover_Letters_Data`,
`/mnt/project/Highlights`, and `/mnt/project/Tech_Expertise` — the names they carry in the
existing Project. Re-uploading them from this folder will name them
`cover-letters-data.md` and so on instead. The instructions now list both forms, so either
naming resolves, but when you replace a file in the Project, delete the old copy rather than
leaving two versions of the same document uploaded.

## Not uploaded, on purpose

- `case-studies/` — deep feature writeups. Their pitchable content is already distilled into
  `cover-letters-data.md`. Upload only if you want long-form detail for follow-up docs.
- `sales/`, `folyo/`, `design-prompts/`, `proposal-log.md` — outreach, checklists, design
  material, and local tracking. Out of scope for cover letters.

## After editing

Any edit to these four files only reaches your proposals once the file is re-uploaded to the
Project. Editing locally is not enough.
